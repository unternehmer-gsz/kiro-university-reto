# Task Setup Skill

Cuando la palabra clave `manage-tasks` sea invocada:
1. Verifica que la especificación en `docs/feature_spec.md` esté actualizada.
2. Asegura que los tipos TypeScript de las tareas cumplan con las reglas de dirección en `.kiro/steering/`.
3. Ejecuta los tests de propiedades con `npm test`.
